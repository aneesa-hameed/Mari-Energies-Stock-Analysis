# 📊 Mari Energies Stock Analysis Dashboard

An interactive Business Intelligence dashboard built in Microsoft Power BI to analyze stock performance metrics, periodic closing values, daily changes, and price directions.

## 🚀 Key Features & Functionality
* **Dynamic Time Intelligence Slicers:** Custom field parameters allowing users to seamlessly switch between Day, Month, Quarter, and Year views.
* **Advanced KPI Cards:** Real-time tracking of Target Price, Buying Price, Min Price, and Max Price with variance indicators.
* **Trend & Volatility Analysis:** Visualizing periodic closing values alongside trendlines to evaluate stock momentum.
* **Volume & Price Direction Insights:** Interactive charts mapping trading volume against bullish, bearish, and neutral market movements.

## 🛠️ Tech Stack & Tools
* **BI Tool:** Microsoft Power BI
* **Data Modeling & DAX:** Calculated columns, measures, and field parameters
* **Design & Layout:** Custom corporate color themes and clean UI/UX for executive presentation
